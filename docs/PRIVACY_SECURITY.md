# Privacy and security principles

- **No personal logins.** The bots never use Duke's passwords, session cookies or personal tokens, and never act as him.
- **Disclosed bots.** Every bot is labeled as a bot in its name and messages.
- **Secrets stay out of Git.** Tokens live in a secrets store. CI scans every file and the full commit history.
- **Human approval** for anything public, financial or security-sensitive.
- **Least privilege.** Community roles grant no permissions, and private channels stay private.
- **No fake engagement.** No fake member counts, auto-viewing, giveaway farming or mass mentions.
- **Simulated means labeled.** Mocked model output is always marked SIMULATED.
- **Defensive security only.** Guardian Forge reads and reports; it doesn't block, scan or attack anything.
- **What this public repo leaves out:** private chat and server identifiers, member data, server addresses, credentials,
  unreviewed source code and open security findings.

Found a problem? Open an issue without sensitive details, and Duke will follow up privately.
